# Guidance: dsagent.sign-in

Owner rules for planning with these methods, each paragraph once with the methods it applies to. They are projections of the owner descriptors (the live `guidance` field); the per-method references link here.

- (dsagent.sign-in.check) Open a sign-in or application entry address in a new tab and report, once the page settled, what it asks of the visitor: sign-in-required (the sign-in monitor sees a sign-in wall, which wallType names, or the page shows a login and password form beside its content, with no wallType), signed-in (no wall and a signed-in account shows), blocked (a human check, bot check or site refusal before any sign-in) or unknown. A page whose sign-in form opens from a control (a header Sign in button) is unknown with signInEntries: sign in on the same checkId with method set to the entry that opens the form. Returns the settled origin and path only, the session, a checkId, and the pageContextId of the opened tab: read it with dsagent.page.observe and close it with dsagent.page.close when done. Fills and submits nothing. At most 20 checks a minute per caller (RATE_LIMITED, wait a minute). For signed-out checks use sessionGroup new with a sessionName, never sign the person's own session out.
