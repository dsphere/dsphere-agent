# Guidance: dsagent.live-tasks

Owner rules for planning with these methods, each paragraph once with the methods it applies to. They are projections of the owner descriptors (the live `guidance` field); the per-method references link here.

- (dsagent.live-tasks.window.open) Use it when the person asks to watch the running tasks. The window opens behind the window the person is using and an open one is never brought to the front: the person switches to it (window already-open when it was open). It changes no task or page and gives you no video: read tasks with dsagent.monitor.snapshot. Refused POLICY_DENIED NOT_PERMITTED when the person's account may not see the Live Task page (the History permission), BROWSER_UNAVAILABLE when the permissions could not be read or the browser did not open the window.
