# Guidance: dsagent.live-tasks

Owner rules for planning with these methods, each paragraph once with the methods it applies to. They are projections of the owner descriptors (the live `guidance` field); the per-method references link here.

- (dsagent.live-tasks.window.open) Use it when the person asks to watch the running tasks. When the window is already open it is brought to the front instead of opening a second one (window focused). It changes no task or page and gives you no video: read tasks with dsagent.monitor.snapshot. Refused POLICY_DENIED NOT_PERMITTED when the person's account may not see the Live Task page (the History permission), BROWSER_UNAVAILABLE when the permissions could not be read or the browser did not open the window.
