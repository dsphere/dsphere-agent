# Guidance: dsagent.mail

Owner rules for planning with these methods, each paragraph once with the methods it applies to. They are projections of the owner descriptors (the live `guidance` field); the per-method references link here.

- (dsagent.mail.account) Use it to address mail to the person, for example a question or a confirmation sent with dsagent.mail.send whose reply you then find with dsagent.mail.search. When configured is false there is no account and email is null; only the person sets one up, in Email → Settings. It never returns servers, user names or passwords.

- (dsagent.mail.read) It reads what the Email panel has synced; a message whose body is still downloading is fetched through the Native Agent first. Reading leaves the messages' read state unchanged and never returns account settings or passwords.

- (dsagent.mail.search) Matches subjects, sender and recipient names and addresses, message bodies, and attachment names and text; plain words match anywhere, and from:, to:, subject:, body: or attachment: narrow one term (quote phrases: subject:"quarterly report"); is:unread, is:read, is:flagged and has:attachment filter; after:YYYY-MM-DD and before:YYYY-MM-DD bound the sent date and newer_than:30d or older_than:2w count back from now (d, w, m, y). Results are newest first with opaque message ids, an excerpt whose matched text is wrapped in ** and attachment names. It searches only what the panel has synced (the newest messages of each synced folder) and never contacts the mail server; indexed and pendingBodies say how much is searchable. It never returns account settings or passwords. When configured is false the person has not set up the Email panel yet.

- (dsagent.mail.send) It is mail sent as the person: write only what they asked for, to the recipients the task names. dsagent.mail.account gives the person's own address. To, Cc and Bcc together hold at most 100 addresses; the subject is one line and the plain-text body at most 50000 characters. An optional html body (tables, inline styles, links) goes with body as its plain-text alternative; it is rebuilt from an email-safe allowlist, so scripts, style sheets, forms and anything that loads from the network are dropped, and images show only by cid: of an inline attachment. attachments are files the caller staged first with the dsagent_upload_file tool (a path on the caller's computer, or base64 chunks), by uploadId; the Native Agent puts the file bytes into the message, the whole of which stays under 5 MiB. Requires an idempotency key: repeating a key with the same message while it is sending or after it was sent returns that result without sending again; a key reused for a different message is refused, and a failed call keeps nothing, so it may be repeated. OUTCOME_UNKNOWN means the server may have accepted the mail: look in Sent with dsagent.mail.search before sending it again. MAIL_ATTACHMENT_NOT_FOUND means an uploadId expired (staged files last 24 hours): stage the file again. When the person turned on Settings → File Uploads (off by default), they are asked in the DSphere side panel before a staged attachment leaves the computer, once per file and recipients: until they answer the call is refused TARGET_BUSY with businessCode FILE_RELEASE_CONSENT_REQUIRED (nothing was sent; wait, then repeat the call with the same idempotencyKey), and a no is POLICY_DENIED with FILE_RELEASE_DENIED (tell the person; do not retry). Replies to stored messages are not supported here.

- (dsagent.mail.sync) Call it before dsagent.mail.search when mail may have just arrived, for example the reply to a question sent with dsagent.mail.send. It refreshes the newest messages of that folder (the panel's sync window): their headers and read/flag state, and removes messages deleted on the server. Bodies follow in the background, so a body-text search can lag (pendingBodies), while dsagent.mail.read fetches a body on demand. A sync already running for the folder is joined. It changes nothing on the server and never returns account settings or passwords. folders lists the synced account's folders; pass one as mailbox to sync it (for example the sent folder).
