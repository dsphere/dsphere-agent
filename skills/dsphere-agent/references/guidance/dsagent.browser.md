# Guidance: dsagent.browser

Owner rules for planning with these methods, each paragraph once with the methods it applies to. They are projections of the owner descriptors (the live `guidance` field); the per-method references link here.

- (dsagent.browser.sessions.list) Call it before opening a site for a task that names an application account, or whose site needs a sign-in: prefer a session whose site state is signed-in and whose accountLabel, observedAccountLabel or account names match the account the task names, and open the page there (default: omit sessionGroup; named: sessionGroup previous with sessionName; account: accountId). accountLabel is the account the person said they signed in with on DSphere's sign-in sheet; signed-in means the person passed a sign-in wall there and no wall was found since, which is evidence, not proof: a page that shows a wall again is handed to the person as usual. Never start a new session or ask the person to sign in again when a matching signed-in session is listed. previousAccountLabel with accountSwitchedAt means the person later signed in there with another account: when the task needs the previous account, do not use that session for it; tell the person. Read-only; no page is opened.
